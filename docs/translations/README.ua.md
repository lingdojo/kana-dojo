## 📖 Про KanaDojo

KanaDojo — це інтерактивна веб-платформа для вивчення японської мови, яка робить опанування хіраґани, катакани, кандзі та словникового запасу інтуїтивним і захопливим. Платформу створено з фокусом на естетику, персоналізацію та ефективне навчання, забезпечуючи глибоке занурення для учнів будь-якого рівня.

Незалежно від того, чи ви тільки починаєте знайомство з базовими силабаріями кана, чи готуєтесь до іспитів JLPT з просунутими кандзі та лексикою, KanaDojo пропонує зосереджений, безвідволікаючий навчальний досвід, який адаптується до ваших уподобань і стилю навчання.

### ✨ Ключові можливості

#### 🎯 **Три навчальні додзьо**

- **Kana Dojo** — вивчення хіраґани та катакани: базові символи, дакутен, йоон та іноземні звукові групи  
- **Kanji Dojo** — вивчення ключових кандзі, впорядкованих за рівнями JLPT (N5, N4, N3, N2)  
- **Vocabulary Dojo** — розширення словникового запасу за рівнями володіння мовою  

#### 🎮 **Чотири динамічні ігрові режими**

1. **Pick** — вибір правильної романізації або перекладу  
2. **Reverse-Pick** — вибір правильного символу за романізацією або перекладом  
3. **Input** — введення правильної романізації або перекладу  
4. **Reverse-Input** — введення правильного символу  

#### 🎨 **Розширена персоналізація**

- **100+ тем** — світлі, темні та випадкові  
- **28 японських шрифтів**  
- **Звукові ефекти** з можливістю вимкнення  
- **Налаштування відображення** Romaji / Kana / Kanji  
- **Гарячі клавіші** для швидкого навчання  

#### 📊 **Відстеження прогресу**

- Миттєвий зворотний звʼязок  
- Підрахунок серій відповідей  
- Детальна статистика навчання  

#### 🌐 **Сучасний веб-досвід**

- Повністю адаптивний дизайн  
- Працює без встановлення  
- Мінімалістичний інтерфейс  
- Плавні анімації на Framer Motion

## 🚀 Початок роботи

### Вимоги
- Node.js 18+
- npm 10+

### Встановлення

1. **Клонування репозиторію**

```bash
git clone https://github.com/lingdojo/kanadojo.git
cd kanadojo
```2. **Встановлення залежностей**

```bash
npm install
``

3. **Зaпуск сервера розробки**
```bash
npm run dev
```

4. **Відкрийте браузер**
Перейдіть за адресою http://localhost:3000

### Збірка для продакшн

```bash
# Створення оптимізованої продакшн-білду
npm run build

# Запуск продакшн-сервера
npm start
```

### Інші команди

```bash
# Запуск ESLint
npm run lint

# Генерація sitemap (автоматично після білду)
npm run postbuild
```

### Вирішення проблем

Якщо під час розробки виникають проблеми, спробуйте такі рішення:

#### Очистка кешу Next.js

**macOS/Linux:**

```bash
rm -rf .next
npm run dev
```

**Windows (PowerShell):**

```powershell
Remove-Item -Recurse -Force .next
npm run dev
```

**Windows (Command Prompt):**

```cmd
rmdir /s /q .next
npm run dev
```
#### Видалення node_modules та перевстановлення

**macOS/Linux:**

```bash
rm -rf node_modules package-lock.json
npm install
```

**Windows (PowerShell):**

```powershell
Remove-Item -Recurse -Force node_modules, package-lock.json
npm install
```

**Windows (Command Prompt):**

```cmd
rmdir /s /q node_modules
del package-lock.json
npm install
```

#### Повне очищення кешу (Ядерний варіант)

**macOS/Linux:**

```bash
rm -rf .next node_modules package-lock.json
npm cache clean --force
npm install
npm run dev
```

**Windows (PowerShell):**

```powershell
Remove-Item -Recurse -Force .next, node_modules, package-lock.json
npm cache clean --force
npm install
npm run dev
```

**Windows (Command Prompt):**

```cmd
rmdir /s /q .next
rmdir /s /q node_modules
del package-lock.json
npm cache clean --force
npm install
npm run dev
```

#### Порт вже використовується

Якщо порт 3000 вже зайнятий:

**macOS/Linux:**

```bash
# Знайти процес, який використовує порт 3000
lsof -i :3000

# Завершити процес (PID замінити на фактичний ID процесу)
kill -9 PID
```

**Windows (PowerShell/Command Prompt):**

```cmd
# Знайти процес, який використовує порт 3000
netstat -ano | findstr :3000

# Завершити процес (PID замінити на фактичний ID процесу)
taskkill /PID PID /F
```

Або просто запустити на іншому порту:

```bash
# macOS/Linux/Windows
PORT=3001 npm run dev
```

### Ключові концепції

#### Потік стану (State Management Flow)

1. Користувач обирає контент у меню.
2. Вибір зберігається у Zustand Stores (`useKanaKanjiStore`, `useVocabStore`).
3. Компоненти тренування читають дані зі Stores для генерації питань.
4. Статистика зберігається в `useStatsStore`.
5. Налаштування користувача зберігаються в `useThemeStore` з persist у localStorage.

#### Архітектура компонентів

- **Dojo-компоненти**: Відповідають за вибір символів/слів.
- **Компоненти тренувань**: Рендерять ігрові режими та обробляють взаємодію користувача.
- **Повторно використовувані компоненти**: Кнопки, картки, модальні вікна тощо.
- **Меню-компоненти***: Навігація та вибір Dojo.

#### Організація даних

- **Kana**: за типом (Hiragana/Katakana) і групами (базові, Dakuon, Yoon, іноземні звуки).
- **Kanji**: за рівнем JLPT (N5-N2), з читанням та значенням.
- **Словниковий запас**: за рівнем JLPT і типом слова (іменники, дієслова тощо).

#### Реалізація ігрових режимів

Кожен режим — динамічна маршрутизація (`/[contentType]/train/[gameMode]`), яка:

1. Читає обраний контент із Store.
2. Генерує випадкові питання.
3. Надає миттєвий фідбек.
4. Відстежує статистику (правильно, неправильно, серія).
