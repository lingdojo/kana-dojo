## 📖 Про KanaDojo

KanaDojo — це захоплива вебплатформа для вивчення японської мови, яка робить опанування хіраґани, катакани, кандзі та лексики веселим і інтуїтивно зрозумілим. Побудована з фокусом на естетику, кастомізацію та ефективне навчання, KanaDojo забезпечує глибоке занурення у процес навчання для користувачів будь-якого рівня.

Незалежно від того, чи ви лише починаєте знайомство з базовими складовими абетками, чи готуєтеся до іспитів JLPT з використанням просунутих кандзі та словникового запасу, KanaDojo пропонує структурований, безвідволікаючий навчальний досвід, який адаптується до ваших уподобань та стилю навчання.

### ✨ Ключові можливості

#### 🎯 **Три тренувальні додзьо**

- **Kana Dojo** — опанування хіраґани та катакани з базовими наборами, дакутенами, йоонами та іноземними звуками
- **Kanji Dojo** — вивчення ключових ієрогліфів кандзі, організованих за рівнями JLPT (N5, N4, N3, N2)
- **Vocabulary Dojo** — розширення словникового запасу за допомогою ретельно підібраних колекцій слів за рівнем складності

#### 🎮 **Чотири динамічні ігрові режими**

Кожне додзьо підтримує чотири режими тренування для закріплення знань:

1. **Pick** — множинний вибір: оберіть правильну романізацію або переклад для показаного символу
2. **Reverse-Pick** — зворотний множинний вибір: оберіть правильний символ для заданої романізації або перекладу
3. **Input** — текстове введення: введіть правильну романізацію або переклад
4. **Reverse-Input** — зворотне текстове введення: введіть правильний символ

#### 🎨 **Розширена кастомізація**

- **100+ тем** — великий вибір світлих і темних тем, а також випадкова тема
- **28 японських шрифтів** — автентичні японські гарнітури для будь-яких естетичних вподобань
- **Звукові ефекти** — приємний аудіовідгук інтерфейсу з можливістю вимкнення
- **Налаштування відображення** — перемикання між Romaji/English та Kana/Kanji у меню вибору
- **Гарячі клавіші** — клавіатурні скорочення для ефективного тренування (можна вимкнути)

#### 📊 **Відстеження прогресу**

- Миттєвий зворотний зв’язок з лічильниками правильних та неправильних відповідей
- Відстеження серій правильних відповідей (streak)
- Статистика для моніторингу навчального прогресу

#### 🌐 **Сучасний вебдосвід**

- Повністю адаптивний дизайн для комп’ютерів, планшетів і смартфонів
- Не потребує встановлення — навчайтеся будь-де з доступом до інтернету
- Чистий, мінімалістичний інтерфейс без зайвих відволікань
- Плавні анімації та переходи на базі Framer Motion

## 🎨 UI та філософія дизайну

KanaDojo поєднує **мінімалістичну естетику** з **максимальною гнучкістю**. Філософія дизайну зосереджена на:

### Мінімалізм понад усе

- Чисті інтерфейси з мінімумом відволікаючих елементів
- Фокус на навчальному контенті
- Інтуїтивна навігація та зрозуміла ієрархія інформації
- Усвідомлене використання вільного простору

### Естетична кастомізація

- Велика бібліотека тем (100+ варіантів) — від м’яких пастельних до яскравих неонових
- Підтримка світлого та темного режимів
- Ретельно підібрані палітри кольорів, зручні для тривалих сесій навчання
- Плавні переходи між темами

### Користувацький досвід

- Плавні анімації та мікровзаємодії для приємного зворотного зв’язку
- Адаптивний дизайн, що красиво підлаштовується під будь-який розмір екрана
- Аудіовідгук для взаємодій (опційно)
- Єдина візуальна мова у всіх розділах

### Японська типографія

- 28 автентичних японських шрифтів різних стилів
- Коректне відображення складних ієрогліфів кандзі
- Чітке розрізнення схожих символів
- Попередній перегляд шрифтів із реальними японськими прикладами тексту

<a id="architecture"></a>

## 🏗️ Архітектура

KanaDojo використовує **архітектуру, орієнтовану на функціональність**, де код організований за можливостями, а не за типами файлів.

### Основна структура

- **features/** — самодостатні модулі за функціональністю
- **shared/** — перевикористовувані компоненти, хуки та утиліти
- **core/** — базова інфраструктура (i18n, аналітика)
- **app/** — App Router Next.js

Докладніше див. `docs/ARCHITECTURE.md`.

<a id="getting-started"></a>

## 🚀 Початок роботи

### Передумови

- Node.js 18.x або новіше
- npm 10.x або новіше

### Встановлення

```bash
git clone https://github.com/lingdojo/kanadojo.git
cd kanadojo
npm install
npm run dev
```

Відкрийте браузер: [http://localhost:3000](http://localhost:3000)
