# Agent Guidelines & Context

## 1. Access Scope

- **Allowed Directories:** Allow access to all directories within this project, including frontend, backend, and configuration folders.
- **Cross-Repository Access:** Allowed to read and write across the entire workspace directory.
- **File System Permissions:** Full permission to create, modify, and delete files as needed to solve the task.

## 2. Execution Preferences

- **Terminal Execution:** Auto-execute terminal commands for installing dependencies, running tests, and starting local servers without requiring explicit manual approval.
- **Execution Policy:** Prefer high-autonomy/turbo execution mode.

## 3. Technology Stack & Rules

- **Primary Languages:** Node.js, TypeScript, React, Python.
- **Coding Standard:** Always write clean, documented code and include error handling.
- **Dependencies:** Feel free to install necessary npm/pip packages automatically if required for the solution.
